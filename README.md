# Wongnuashuajing Gang Dashboard

Static UI preview for the Wongnuashuajing FiveM gang management dashboard.

## Current Scope

- Dark gold luxury gang dashboard UI
- Official crew image hero and visual sections
- Mock role login for Boss, Admin, Member, and Recruit
- Role-based UI visibility for member management, events, and recruit states
- Static deploy support for Vercel

## Deploy

This project can be imported directly into Vercel as a static site.

No build command is required.
